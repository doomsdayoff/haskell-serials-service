# Сериалы

Консольный каталог сериалов на Haskell. Курсовая работа по дисциплине
«Функциональное и логическое программирование», ТУСУР, кафедра АОИ, 2024.

Приложение читает каталог из `serials.json`, позволяет отобрать сериалы по
жанру, актёру или режиссёру, отсортировать выборку по рейтингу или году
и найти сериал по подстроке названия, режиссёра или года.

## Сборка и запуск

```
cabal build
cabal run serials
cabal test
```

## Структура

| Модуль          | Назначение                                             |
|-----------------|--------------------------------------------------------|
| `Serials.Types` | тип `Serial` и загрузка каталога из JSON через Aeson    |
| `Serials.Query` | чистые функции фильтрации, сортировки и поиска          |
| `app/Main.hs`   | текстовое меню и ввод-вывод                             |
| `test/Spec.hs`  | тесты на HUnit                                          |

Вся логика отбора вынесена в `Serials.Query` и не зависит от IO, поэтому
тесты работают с ней напрямую, без эмуляции пользовательского ввода.

## Формат данных

```json
{
  "title": "Breaking Bad",
  "genre": ["Drama", "Crime", "Thriller"],
  "actors": ["Bryan Cranston", "Aaron Paul"],
  "director": "Vince Gilligan",
  "country": "USA",
  "year": 2008,
  "rating": 9.5,
  "duration": 47,
  "seasons": 5
}
```

Имена полей записи `Serial` совпадают с ключами JSON, разбор выводится
автоматически через `Generic`.
